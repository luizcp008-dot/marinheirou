Privacy Policy: Marinheirou Publicador

Last updated: October 30, 2026

Marinheirou Publicador is a private tool used only by the owner of the Marinheirou channel. It is not available to the public.

What data it accesses

With the owner's permission, through Google OAuth, the tool uses the YouTube Data API and the YouTube Analytics API to:

  • upload videos to the owner's own channel;
  • update titles, descriptions and thumbnails of the owner's own videos;
  • read statistics of the owner's own channel and videos, such as views, impressions, click-through rate and retention.

How the data is stored

The access token and the statistics are stored only on the owner's personal computer. They are never sold, shared with third parties, or used for advertising.

Google API Services

The use of information received from Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements. The tool also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
